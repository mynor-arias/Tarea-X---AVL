# semana-avl

Implementacion de un arbol AVL para ranking academico por skill_score.
Tarea de estructuras de datos - proyecto parcial.

## Archivos

- `Student.h` - estructura del estudiante
- `AVL.h` / `AVL.cpp` - implementacion del arbol AVL
- `main.cpp` - menu principal

## Como compilar

Abrir la carpeta en CLion, detecta el CMakeLists.txt automaticamente y compilar con el boton Run.

## Funciones

1. Insertar estudiante
2. Ver ranking ordenado por skill score
3. Buscar estudiante por skill score
4. Ver estadisticas del arbol (altura, balance, total nodos)
